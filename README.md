# 敦煌光迹 · Mogao Daylight Timelapse

一个基于 Three.js 的莫高窟白昼光影体验。120 秒时间线以非线性方式覆盖敦煌当地约 07:30–18:30 的白昼，太阳方向、日照洗光、柔和阴影、尘粒和面部受光由同一个时间函数驱动。主体采用莫高窟第 328 窟唐代《跪姿侍立菩萨》的真实摄影测量扫描；可见洞窟空间按莫高窟人工洞窟研究重建为研究导向的原创环境。

## 运行

```bash
npm install
npm run dev
```

打开 HyperFrames Studio 后可拖动时间轴。页面底部的控件还支持：

- 播放／暂停
- 0–120 秒时间拖动
- 0.5× / 1× / 4× / 12× 速度
- 日期切换
- 键盘空格播放，左右方向键微调时间

## 交互观察

- Studio 页面中可拖动画面旋转视角，滚轮拉近/拉远，双击或按 `R` 复位
- `光流` 按钮用于增强尘粒与柔和光雾的连续流动；太阳方向仍由日期和时间轴决定
- `?mode=render` 或 `?render=1` 进入无鼠标输入的电影渲染模式
- 自动播放、鼠标观察和流光增强共享同一个时间状态，不会产生独立的光照动画
- 本版本只渲染太阳与白昼环境，不显示月亮或月光

## 交互播放

Studio 编辑器会拦截预览 iframe 的鼠标事件；交互体验请使用轻量播放器：

```bash
npm run play
```

然后打开：

```text
http://127.0.0.1:3003/composition/interactive.html
```

这个入口显式启用了 HyperFrames Player 的 `interactive` 模式，并移除外层播放条，才可以使用画布拖动、滚轮缩放、双击/R 复位和光流按钮。根路径 `http://127.0.0.1:3003/` 是默认只读播放器。`npm run preview` 仍然用于 Studio 编辑和检查。

## 发布分享

项目已经提供公开发布脚本：

```bash
npm run publish:public
```

它会把当前项目上传到 HyperFrames 的公开分享地址。上传前会先确认项目状态；渲染 MP4 仍需单独明确执行 `npm run render`。当前修改不会自动渲染视频。

## 光照模型

- 地理坐标：敦煌 `40.142°N, 94.661°E`
- 太阳位置：本地 SunCalc 固定依赖，按真实日期与当地太阳时计算
- 主光：低对比、阴影柔和的太阳方向光；不把孔洞光斑做成硬直条带
- 辅助光：无阴影的漫射日光与砂岩反弹光，保留菩萨和壁面的体积
- 可见光雾：低不透明度、宽羽化的三层体积光，加一层面向镜头的解释性丁达尔光锥；太阳仍决定色温、强度和方向
- 尘粒：24,000 个固定种子空气粒子 + 6,500 个可读微尘 + 1,800 个光锥内部尘粒，形成可见的丁达尔散射
- 面部局部光：使用宽角度、高 penumbra 的软聚光，不产生锐利光斑
- 主体模型：第 328 窟唐代侍立菩萨扫描，按记录整体高度 1.219 m 建模；顶点彩绘为主，8K JPEG 作为低强度微表面细节
- 可见后壁与侧壁：使用已标注来源的公有领域第 217 窟时期壁画作为参考层，不宣称为第 328 窟壁画

## 文件

- `index.html` — 1920×1080 组合、120 秒时间控件和确定性进度轴
- `interactive.html` — 显式开启 `hyperframes-player` 交互属性的轻量网页入口
- `scene.js` — Three.js 场景、太阳计算、材质、几何、柔化光雾和尘粒
- `documented-cave.js` — 研究导向的莫高窟类型主室、浅壁龛与开口几何
- `RESEARCH.md` — 洞窟空间研究、版权边界和实现取舍
- `BRIEF.md` — 已确认创作简报
- `STORYBOARD.md` — 120 秒白昼光线分镜与锁定项
- `storyboard.htm` — 静态构图草图（非 HyperFrames 入口）
- `frame.md` — 视觉与物理规则
- `vendor/` — 固定版本 Three.js、GLTFLoader、BufferGeometryUtils、SunCalc 与 GSAP 浏览器依赖
- `assets/ATTRIBUTION.md` — 第 328 窟扫描、公有领域时期壁画参考的来源、许可与署名要求

该场景的菩萨本体是真实文物扫描；洞窟空间是尊重史实的研究导向原创环境，不宣称是第 328 窟的测绘复原。后壁与侧壁的公有领域第 217 窟壁画只作为时期与视觉参考层，来源见 `assets/ATTRIBUTION.md`。
